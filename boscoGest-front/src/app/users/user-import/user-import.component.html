Importación Masiva de Usuarios

info Guía de Uso

¿Qué hace esta funcionalidad?

Esta herramienta permite crear múltiples usuarios simultáneamente mediante un archivo CSV. Es ideal para dar de alta grupos grandes de usuarios de forma rápida y eficiente.

Cómo usar:

  1. Descarga la plantilla CSV haciendo clic en el botón "Descargar Plantilla"
  2. Abre el archivo con Excel, Google Sheets u otro editor de hojas de cálculo
  3. Rellena los datos de los usuarios siguiendo el formato de la plantilla
  4. Guarda el archivo como CSV (delimitado por comas)
  5. Sube el archivo usando el botón "Seleccionar Archivo"
  6. Haz clic en "Importar Usuarios" para procesarlo

Campos del CSV:

Campo {{ field.name }} Descripción {{ field.description }} Obligatorio {{ field.required ? 'Sí' : 'No' }} Ejemplo {{ field.example }}
warning
Importante:
  • Todos los campos deben estar entre comillas dobles ("")
  • Los usuarios creados deberán cambiar su contraseña en el primer inicio de sesión
  • El email y DNI deben ser únicos en el sistema
  • Se crearán automáticamente membresías en todas las entidades padre
